# 🌌 Acerca del proyecto

**Social Events Management App** es una plataforma web orientada a la organización y administración de eventos sociales como bodas, cumpleaños, conferencias, fiestas privadas y celebraciones especiales.

El sistema fue diseñado para:

- 🎉 Gestionar eventos sociales
- 📅 Administrar reservaciones
- 👥 Gestionar invitados
- 🪑 Organizar mobiliario y servicios
- 📦 Controlar paquetes y eventos
- 💳 Administrar pagos
- 🔐 Gestionar usuarios y accesos
- 🌐 Facilitar la planificación de eventos

# 👨‍💼 Módulos del sistema

## 🎉 Event Module

Este módulo administra todos los eventos sociales registrados en la plataforma.

### Funcionalidades:

- ➕ Crear eventos
- 📅 Gestión de fechas
- 📍 Selección de ubicaciones
- 📝 Configuración de detalles
- 📊 Administración de eventos

---

## 👥 Guest Module

Este módulo administra los invitados y asistentes de cada evento.

### Funcionalidades:

- 👤 Registro de invitados
- 📩 Confirmación de asistencia
- 📋 Gestión de listas
- 🔔 Notificaciones
- 📊 Control de asistentes

---

## 🛠️ Admin Module

Este módulo funciona como administrador principal del sistema.

### Funcionalidades:

- 👥 Gestión de usuarios
- 📊 Dashboard administrativo
- 💰 Supervisión de pagos
- 📅 Administración de eventos
- 🔐 Gestión de accesos

# ⚡ Instalación

## 📋 Requisitos

- Node.js 18+
- npm o yarn
- Visual Studio Code

# 🚀 Configuración del proyecto

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/PlataformaOrganizacionEventosSociales.git
```

---

## 2️⃣ Entrar al proyecto

```bash
cd PlataformaOrganizacionEventosSociales
```

---

## 3️⃣ Instalar dependencias

```bash
npm install
```

---

## 4️⃣ Ejecutar aplicación

```bash
npm run dev
```

---

## 5️⃣ Abrir en navegador

```bash
http://localhost:5173
```
